# Shaman — área de organização

Esta pasta é um espaço de desenvolvimento; o Foundry não a trata como um Compendium Pack.

Quando os compêndios do Shaman forem exportados pelo Foundry, os bancos de dados reais deverão ficar em `packs/` e ser registrados em `module.json`.

IDs planejados para os futuros compêndios:
- `shaman-class`
- `shaman-features`
- `shaman-practices`
- `shaman-feats`
- `shaman-spells` (somente se houver magias próprias)

Depois de criar cada pack no Foundry, atualize a lista `packs` da pasta `Shaman` em `module.json` com os IDs efetivamente usados. Não adicione entradas de pack antes de os respectivos bancos de dados existirem.
